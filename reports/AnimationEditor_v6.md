# Редактор анимаций сущности — 2026-10-01

Добавлены независимые вкладки Постройка, Idle, Уничтожение и именованные Custom.
Можно копировать анимации, удалять custom с Undo, переиспользовать изображения постройки
для других состояний и экспортировать весь набор одной сущности. Одно изображение допустимо.

Звуковой режим имеет импорт файлов и drag-and-drop, waveform всех каналов, move/trim,
source offset, громкость, mute/solo, fade in/out, duplicate/split/delete и relink.
Курсор, рабочая область, пауза, цикл и скорость общие с анимацией. Именованные markers
помогают синхронизировать события; изменение длительности сохраняет секунды ключей и меток.

Schema v6 импортирует v2–v5. IndexedDB сохраняет все вкладки и Blob-исходники PNG/аудио
в одном record. Production JSON содержит стабильные assetId; файлы отдельно размещаются
в asset registry или перепривязываются через Relink. Web Audio остаётся в клиентском слое,
а Pixi player и simulation не получают зависимости от browser audio.

## Свежие проверки

- `npm run typecheck`: проходит, включая отдельный simulation tsconfig.
- `npm run lint`: проходит.
- `npm run build`: проходит; Vite сообщает предупреждение о существующем крупном JS chunk.
- `npm run format:check`: проходит после форматирования изменённых файлов и settings.json.
- `npx vitest run src/ui/AnimationSandbox src/game/buildings`: 33 теста проходят, 5 файлов.
- `npm run test`: 292 проходят, 5 падают, всего 297 тестов / 45 файлов.

Оставшиеся падения относятся к незатронутым этим изменением модулям:

1. `src/app/AppSettings.test.ts`: ожидание gravity 30 расходится с default 40.
2. `src/game/impacts/ricochetIntegration.test.ts`: два теста lifecycle/preview рикошета.
3. `src/game/terrain/terrainSettling.test.ts`: количество Soil после осыпания и слишком
   узкий тестовый мир для текущих installation spawns.

Ошибки не скрывались удалением тестов или изменением их ожиданий. Два существующих
ошибочных объявления кортежей в renderer/physics test уточнены для strict typecheck;
GameScene ждёт инициализации Pixi и защищён от обращения к уничтоженному renderer
при смене режима, чтобы ранний mount не оставлял preview пустым.

## Проверка в браузере

На отдельном localhost:5174 проверены импорт WAV и PNG, отображение waveform, громкость
и fade, покадровая навигация, marker, split/Undo, дублирование и независимость параметров
вкладок, удаление custom/Undo, переиспользование artwork, увеличение длительности с
сохранением marker на прежней секунде. После полной перезагрузки восстановлены active
tab, четыре композиции, PNG, WAV, markers и разные значения громкости исходной/копии.
Проверено завершение рабочей области при скорости 2× и продолжение playback при переходе
в GAME и обратно. В проверяемой вкладке после этих действий console errors отсутствуют.

Экспорт всей сущности покрыт JSON round-trip тестом; браузер принял действие Export Entity
JSON, но не предоставил download event/path, поэтому сохранённый файл отдельно не проверен.
